🧭 Stadium Wind Orientation Audit

This is the safety check for the weather engine. It shows the actual home park being used, the hard-coded stadium coordinates, the CF/LF/RF bearings, the live wind direction after the OpenWeather 180° flip, and which hitter side the model thinks benefits.

How to use this: CF Bearing is home plate → center field. LF is CF - 35°, RF is CF + 35°. OpenWeather gives wind FROM; the model flips it 180° to Wind TO, then compares that against LF/CF/RF. If a CF Bearing is wrong, the boost side can be wrong even when the API weather is perfect.
